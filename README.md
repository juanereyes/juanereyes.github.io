# Juan Esteban Reyes Beltrán Personal Website

This is the first draft of a personal website designed as a sleek personal lab:
creative on the homepage, professional for academics, and portfolio-oriented for
projects.

## Pages

- `index.html`: personal homepage and entry points
- `academics.html`: research, papers, and academic projects
- `projects.html`: games, apps, and technical projects
- `cv.html`: placeholder for a future CV upload

## Local preview

Because this site has no build step, it can be opened directly in a browser or
served with any static file server.
